# WireGuard Linux GUI v1.2.0

This release renames the client from wireguird to WireGuard Linux GUI and
introduces a GTK4/Libadwaita interface.

## Changes

- Redesigned tunnel sidebar and Interface/Peer details, with import, export,
  creation, and editing of WireGuard profiles.
- Updated system tray menus with tunnel controls, network labels, and active
  connection indicators.
- Refreshed tunnel status when connections change outside the app, including
  changes made through `wg-quick` or systemd.
- Added a per-user **Start at login** preference and improved the preferences
  save, cancel, and unsaved-change workflow.
- Added an About dialog with the application version, build date, project links,
  and third-party notices.
- Updated installation instructions, usage documentation, and screenshots.

## Installation

Packages target Linux amd64. The Debian package requires GTK 4.14 or newer,
Libadwaita 1.5 or newer, `wireguard-tools`, and `resolvconf`.

Download the `.deb` asset, quit any running copy through its tray menu, then run
from the download directory:

```sh
sudo apt install ./wireguard-linux-gui_1.2.0_linux_amd64.deb
```

Open **WireGuard** from Applications after installation.

## Known limitation

The optional update checker still checks the original wireguird repository.
Download updates for this renamed client from
[this project's releases](https://github.com/nh-kng/wireguard-linux-gui/releases).
